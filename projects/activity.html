Human Activity Recognition

A comparison of dimensionality-reduction methods for classifying sensor-based human activities.

Python · PCA · LDA · SVC

What I explored

  • The official UCI HAR training and test partitions remain separate.
  • Scaling, PCA and LDA learn from the training partition only.
  • SVC classification is evaluated with accuracy, precision, recall and F1.

Run the project

Provide the extracted UCI HAR dataset, set HAR_DATASET_DIR if needed, then run human-activity-recognition.ipynb.

Scope & limitations

The dataset is external and not bundled. The complete notebook was exercised using the official dataset. This is a classification study, not a mobile sensing product.

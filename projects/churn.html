Customer Churn Classification

An exploratory comparison of logistic regression and a decision tree using telecom customer data.

Python · scikit-learn

What I explored

  • Numeric conversion and one-hot encoding.
  • Exploratory plots for churn and monthly charges.
  • An 80/20 holdout with accuracy and classification reports.

Run the project

Install the notebook requirements and run customer-churn.ipynb in Jupyter. The notebook downloads the IBM Telco dataset.

Scope & limitations

An exploratory notebook, not a deployed prediction service. Missing-value imputation is fitted to the training partition only; evaluation remains exploratory. No new performance result is claimed here.

Clinic Management CLI

A console application that brings clinic records, staff roles, pharmacy and finance workflows into one file-based system.

Java · File I/O

What I explored

  • Role-based menus for administration, reception, doctors, finance and pharmacy.
  • Local text files hold application records.
  • A menu-driven workflow designed for learning Java file handling.

Run the project

Java 17 and Maven. Run mvn compile exec:java from the clinic-management-cli repository directory.

Scope & limitations

Demo login and plain-text storage make this an educational application. It is not suitable for real patient records or production access control.

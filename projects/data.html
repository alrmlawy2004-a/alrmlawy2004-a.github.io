Storage & Reliability Experiments

Notebook experiments covering storage formats, Parquet partitions, compression estimates and simulated HDFS failures.

Python · pandas · PyArrow

What I explored

  • Compare CSV, JSON, Parquet, Feather and Pickle storage.
  • Explore partitioned synthetic sales data.
  • Simulate data-block loss across replicated nodes.

Run the project

Install the data-systems requirements and run the notebooks in a dedicated scratch directory. Use reduced dataset sizes for a quick check.

Scope & limitations

The HDFS model is a local simulation. Timing comparisons are exploratory; in-memory filters and disk reads are different workloads. Pricing values are exercise assumptions.

Penguin Data Exploration

An exploration of species measurements using distribution plots and statistical tests.

Python · SciPy · Seaborn

What I explored

  • Inspect the Palmer Penguins dataset.
  • Compare species through pair plots.
  • Explore one-way ANOVA and contingency-table tests.

Run the project

Install the pattern-recognition requirements and run penguin-analysis.ipynb.

Scope & limitations

Exploratory statistical work. Interpretation depends on assumptions, missing values and the chosen groups; it is not a published research result.

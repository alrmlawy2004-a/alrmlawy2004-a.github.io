Phone Directory

An in-memory contact directory with a menu for creating, finding, editing and removing entries.

Python · Console UI

What I explored

  • Phone and identifier format validation.
  • Add, list, search, edit and delete operations.
  • Environment-configured demo login with a three-attempt limit.

Run the project

Set DIRECTORY_USERNAME and DIRECTORY_PASSWORD, then run python phone_directory.py.

Scope & limitations

Data disappears when the application exits. Use fictional records. The login is a local demonstration, not production authentication.

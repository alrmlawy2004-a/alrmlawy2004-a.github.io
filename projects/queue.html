Customer Service Queue

A console workflow using a queue for waiting customers and a stack for served customers.

Java · Queues · Stacks

What I explored

  • Custom fixed-capacity queue and stack structures.
  • Customer waiting identifiers.
  • Employee and administrator menus.

Run the project

Use Java 17; the Maven project identifies its main class in pom.xml.

Scope & limitations

The circular queue reuses freed slots and guards capacity. Served history holds 20 records. Demo credentials and in-memory users limit it to educational use.

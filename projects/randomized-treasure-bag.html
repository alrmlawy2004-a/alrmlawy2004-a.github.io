Run the project

Java 17 or later is required. From this directory: shell mvn compile exec:java Main class: treasure.Ass1320220837. Without Maven, use PowerShell: powershell $sources = Get-ChildItem src -Recurse -Filter *.java javac -encoding UTF-8 -d out $sources.FullName java -cp out treasure.Ass1320220837 These are standalone learning exercises. Compilation and representative behaviour were checked with JDK 23.

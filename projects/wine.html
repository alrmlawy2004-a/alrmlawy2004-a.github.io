Wine Quality Classification

A binary classification study comparing linear support vector models and XGBoost on red and white wine data.

Python · SVM · XGBoost

What I explored

  • Quality is mapped into two classes using a threshold of 5.
  • Training-only standardization supports the linear models.
  • Accuracy, F1 and score-based ROC-AUC summarize the holdout results.

Run the project

Place winequality-red.csv and winequality-white.csv in data/, install the requirements and run wine-quality.ipynb.

Scope & limitations

External data is required. The large-C linear model approximates a hard-margin configuration. Results use a single holdout, without cross-validation.
